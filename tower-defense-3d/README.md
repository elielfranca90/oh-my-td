# 🏰 Tower Defense 3D (MVP)

Protótipo de jogo estilo *Tower Defense* 3D desenvolvido com **Three.js**, **TypeScript** e **Vite**. O projeto executa diretamente no navegador com foco em alta performance e arquitetura modular, separando rigorosamente a lógica matemática da renderização visual.

---

## 🚀 Como Executar o Projeto

**Pré-requisitos de Ambiente:**
* Node.js (versão 18 ou superior)
* Gerenciador de pacotes (npm, yarn ou pnpm)

**Passos de Inicialização:**
1. Instale as dependências com `npm install`
2. Inicie o servidor de desenvolvimento com `npm run dev`
3. Gere a build otimizada para produção com `npm run build`

---

## 🛠️ Stack Tecnológica

|Componente|Tecnologia Escolhida|Propósito|
|:---|:---|:---|
|**Linguagem**|TypeScript 5.x|Tipagem estática e orientação a objetos|
|**Engine Gráfica**|Three.js|Renderização 3D via WebGL|
|**Bundler**|Vite|Servidor de desenvolvimento e build rápida|
|**Controles**|OrbitControls|Manipulação nativa da câmera 3D|
|**Documentação**|Mermaid|Geração de diagramas e fluxos|
